# Tanjeem Farhana Raha — Academic Portfolio

A static, responsive academic portfolio built from Tanjeem Farhana Raha's CV. It is designed for graduate-program outreach and highlights transportation engineering, research, teaching, technical work, and selected civil engineering projects.

## Run locally

No build step or package installation is required. Open `index.html` directly, or serve the folder with any static web server.

For example, with VS Code, use the Live Server extension and open `index.html`.

## Publish with GitHub Pages

1. Create a public GitHub repository.
2. Upload all files in this folder to the repository's default branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the default branch and the `/ (root)` folder, then save.

The site uses relative paths, so it works both at `username.github.io` and at `username.github.io/repository-name`.

For a custom domain later, add the domain in the GitHub Pages settings and follow GitHub's DNS instructions. GitHub will create or update the `CNAME` file when configured through the settings.

## Update content

- Page content: `index.html`
- Colors and layout: `styles.css`
- Navigation behavior: `script.js`
- Optional downloadable CV path: `Raha_cv.pdf` (the private local copy is excluded from this repository)

The site intentionally does not publish the private CV or the home address, phone number, and referees' phone numbers it contains. A public-safe CV can be added later at `Raha_cv.pdf` without changing the existing website links.
